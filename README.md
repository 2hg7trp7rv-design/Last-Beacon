# LAST BEACON — 最後の灯火

広い拠点を上下左右に見回し、施設・住民・資源を管理する縦画面2.5D Web/PWAゲームです。固定された1画面を連打する形式ではなく、マップ移動そのものがゲーム進行に組み込まれています。

## 操作

- 1本指ドラッグ: 拠点マップを上下左右へ移動
- 2本指ピンチ: マップを拡大・縮小
- 施設を短くタップ: 施設の選択、チュートリアル操作
- 下部メニュー: 施設一覧、住民配属、周辺探索

施設上からドラッグを始めてもタップ操作は発火しません。HUDと下部メニューはカメラ移動の影響を受けず、常に画面上へ固定されます。

## 最初のプレイループ

1. マップをドラッグして南西の回収工房を探す
2. 回収工房で廃材を回収する
3. 中央広場へ戻り、最後の灯火をLv.2へ強化する
4. マップ上端まで移動し、取り残された生存者を救助する
5. 南東の食料温室へ移動し、救助した住民を配属する
6. 自動生産で資源を増やし、施設を強化する
7. 灯火Lv.3で北部ゲートから探索隊を派遣する

回収工房・食料温室・送電リレーは、施設レベルと配属人数に応じて廃材・食料・電力を生産します。探索では居住枠に空きがあれば新たな生存者を救助できるため、シェルター強化と住民配属が次の拡張につながります。進行は端末内へ保存され、最大4時間分のオフライン生産を復帰時に精算します。

## 起動

必要環境は Node.js 22.12 以上です。

```bash
npm install
npm run dev
```

本番ビルドと確認:

```bash
npm run build
npm run preview
```

## GitHub → Vercel

環境変数や `vercel.json` は不要です。VercelでGitHubリポジトリをImportし、次の設定を使用します。

- Framework Preset: Vite
- Root Directory: `./`
- Build Command: `npm run build`
- Output Directory: `dist`
- Install Command: `npm install`

本番URLをiPhoneで開き、共有メニューから「ホーム画面に追加」すると縦向きPWAとして起動できます。

## 保存仕様

- 保存先: 端末・ブラウザ内の `localStorage`
- 保存タイミング: 操作後、生産時、タブ非表示時、復帰時、ページ離脱時
- オフライン生産: 最大4時間
- 旧バージョン: v1セーブをv2へ自動移行
- 初期化: 「周辺」メニュー内の「チュートリアルを最初から」

アカウントやクラウド同期はまだありません。ブラウザデータを消すと進行も消えます。

## 構成

```text
src/
  game/
    LastBeaconScene.ts  大型ワールド、カメラ、ドラッグ・ピンチ、施設演出
    state.ts            進行、施設、配属、生産、探索、保存
    audio.ts            ユーザー操作後に鳴る合成効果音
  main.ts               HUD、施設・住民・探索メニュー、PWA更新UI
  styles.css            縦画面UI、Safe Area、レスポンシブ
public/
  assets/                軽量化済みWebPゲーム素材
  fonts/                 日本語UIフォント
```
